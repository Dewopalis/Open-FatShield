# Security reports

Open FatShield is an experimental kernel driver and companion app. The current
alpha is the only maintained version; it has not received a complete security audit.

Report exploitable vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Dewopalis/Open-FatShield/security/advisories/new).
Include affected versions, reproduction steps and potential impact. Keep exploits
and pairing secrets out of public issues while a report is being investigated.
For ordinary connection failures and compatibility questions, use the issue forms.
